# SUJATA Fine Jewels 💎✨

SUJATA Fine Jewels is a luxury e-commerce web application built with Next.js (App Router), TypeScript, and Tailwind CSS. It features 3D product viewing, dynamic Certificates of Authenticity, an integrated customer profile with live order, bag, and wishlist management, and a complete admin panel for store operations.

## ✨ Features

- **Storefront & Catalog**: Browse rings, necklaces, earrings, bracelets, and pendants filtered by metal, gemstone, and occasion.
- **3D Jewellery Viewer**: Interactive 360-degree product inspection powered by Three.js.
- **Customer Portal**: Integrated profile layout with orders, wishlist, saved addresses, and shopping bag.
- **Certificates of Authenticity**: Dynamic PDF certificate generation and download for verified orders.
- **Admin Management Panel**: Dashboard, product management, order processing, and certificate lifecycle management.

## 🚀 Getting Started

### Prerequisites
- Node.js v18.x or higher
- npm or yarn

### Setup & Installation

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
